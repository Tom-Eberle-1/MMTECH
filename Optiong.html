TB1-01 Scope of works

What we take off your package.

We work the way M&E packages are actually let — a defined scope, delivered to drawing, evidenced at handover.

SOW / 01

Containment & cable installation

Tray, basket and conduit for controls networks. LSZH control and comms cabling installed to route drawings, segregated and dressed properly — not run wherever there's space.

SOW / 02

Panel & field terminations

Control panel and field device terminations to schematic. Every core ferruled and identified to the point schedule, so the commissioning engineer isn't chasing unlabelled wiring.

SOW / 03

Point-to-point testing & commissioning support

Continuity and point-to-point checks recorded against the points list before power-up, then attendance through commissioning and witnessing until sign-off.

One trade, one environment. We don't spread across general electrical work — the focus is BMS and control wiring on data centre programmes, done to the standard those sites demand.

TB1-04 Delivery sequence

How a package runs.

The same sequence every controls package on a data centre follows — because it's the actual order of the work, not a marketing diagram.

IMG-04 / DELIVERY AWAITING SITE PHOTOGRAPHY Suggested shot: wide view of a containment run or data hall corridor mid-install — shows scale of environment. No identifiable signage.
STG-1 / FIRST FIX

Containment install

Tray, basket and conduit routes set out and installed to drawing, coordinated with other trades on the ceiling grid.

STG-2 / CABLING

Control cable installation

Control and comms cabling pulled, dressed and segregated. Glanding and entries to panel spec.

STG-3 / TERMINATION

Terminate & ferrule

Panel and field terminations to schematic. Every core identified against the point schedule.

STG-4 / TESTING

Point-to-point

Continuity and P2P checks recorded per point, faults cleared before energisation. Test sheets issued.

STG-5 / COMMISSIONING

Commissioning & witnessing

Attendance through BMS commissioning, fault-finding support, and witnessed demonstrations with the systems integrator.

STG-6 / HANDOVER

Documentation

Marked-up drawings, test records and completion documentation issued for the O&M pack.
